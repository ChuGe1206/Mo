# Security policy

Mo is an input method and therefore handles highly sensitive local data. Please do not report vulnerabilities in a public issue.

Until a dedicated private reporting channel is published, contact the maintainers privately before sharing exploit details. Include the affected commit, Windows version, reproduction steps, and whether input text, user dictionaries, IPC boundaries, package verification, or installer privileges are involved.

Do not attach real user dictionaries, raw keystroke traces, surrounding text, clipboard contents, passwords, full-memory dumps, or other private data. Use synthetic samples.

The project will publish supported release lines and a response SLA before the first public binary release.
