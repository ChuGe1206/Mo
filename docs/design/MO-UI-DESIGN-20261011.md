## 视觉与页面

默认“纸白＋墨绿”，实体不透明背景、轻阴影、细边界；使用 4/8 px 间距节奏、
8/12/16/20 px 圆角，正文 14 px、候选 16 px。气泡为 520 px 横排或
340 px 竖排的设计样例；实现需按 Windows DPI、候选长度和显示器 work area 自适应。

四个设置页面（设计画板为 1100 × 760）：

| 页面 | 主要内容 |
| --- | --- |
| 常用设置 | 全拼/双拼、简繁体、候选注释、Emoji |
| 外观与皮肤 | 设置界面主题、五款皮肤、自定义入口、实时气泡预览 |
| 隐私与学习 | 本地学习、隐私模式、暂停学习与恢复原偏好的解释 |
| 自定义皮肤 | 背景/强调/文字色、圆角、字号、竖排样例、导入/保存为新皮肤入口 |

左侧仅三项常用导航，右侧分组卡片；底部统一恢复默认、重新读取、保存更改。
Win10 实施需适配可用工作区；在 1366 × 768 等较小桌面缩短窗口、滚动内容，
保持底部保存区可见，不能直接将设计画板尺寸硬编码为最小窗口。
保留“已保存”“另一窗口已更新”“另一窗口正在保存”三种状态的设计。
控件为可编辑视觉稿；原型连接页面导航、自定义入口和返回，不声称输入框、
颜色修改、导入或保存已与应用逻辑绑定。

候选气泡：

- 纸白：默认轻盈风格；夜墨：深色专注。
- 薄荷：清爽绿调；暮霞：柔和暖调；墨竹：东方绿调与原创竹叶矢量。
- 系统高对比度：独立示例，实际色值服从 Windows 系统，优先于皮肤。
- 横排/竖排均保留候选序号、首选高亮、确认提示及页码；不抢输入焦点。
- 内容均是合成候选和示例句，不使用真实输入、剪贴板或用户词典。

## 与现有实现的对应

| 设计项 | 当前状态 / 后续工作 |
| --- | --- |
| 输入方案、简繁体、注释、Emoji、本地学习、隐私、明暗主题 | 现有功能；新 UI 应复用 SettingsController / PrimaryPreferences |
| 显式保存、读取、冲突拒绝和保留当前编辑 | 保留 ADR 0057 的控制器契约，不改成未验证的自动保存 |
| 输入方案在当前输入结束后生效 | 保留空闲边界替换会话 |
| 系统高对比度、颜色变化重绘、不抢焦点 | 保留 ADR 0058 / CandidateWindow 合同 |
| 横排、皮肤选择、自定义色、圆角、字号、导入 | 新设计功能，未实装；需要新增设计/格式决策与版本兼容验证 |
| 设置界面独立跟随系统主题 | 新设计；当前 theme 是候选主题，不能将二者错误复用 |
| 候选条数 | 当前仅保留该字段；本提案没有新增可用控件来假装已实现 |

Figma 支持的中文字体仅含 Noto Sans SC，已验证并加载 Regular/Medium/Bold；
设计文本统一使用它。现有 Win10 候选窗口字体是 Microsoft YaHei UI；
实施时先核对原生字体的字宽与行高。这里没有打包或分发字体文件。

## 组件与可编辑性

新文件无既有页面或 Code Connect 映射。已检查可用库并搜索 Simple Design System
的 Button/Switch/Select、颜色、间距与样式；本提案采用 Mo 自有中文桌面与皮肤合同，
创建本地组件。没有复制竞品皮肤、品牌图或截图进入 Figma 设计层。

- 28 个主组件，包含 12 个气泡变体、五款皮肤卡，以及按钮/开关/导航/设置行。
- 三个变量集合；62 个语义/几何变量，颜色语义 alias 到基础色；各变量注明 scope
  与 WEB code syntax。Starter 单 mode 下用皮肤命名空间和组件变体区分配色。
  WEB syntax 是交接命名，不说明原生应用已经使用 CSS。
- 七种共享中文文字样式、两种阴影样式。
- 设置展示画板：196 TEXT、153 FRAME、53 INSTANCE、9 VECTOR、3 ELLIPSE；
  气泡展示：128 TEXT、74 FRAME、7 INSTANCE、1 VECTOR。
- 两个展示画板的 IMAGE fill 节点均为 0，完整 UI 由文字、组件与矢量构成。
- 墨竹装饰为本轮原创 SVG 路径，Apache-2.0；没有引入竞品素材或远端图片。
