# ADR 0003：零配置普通用户体验

- 状态：Accepted
- 日期：2026-09-11

## Context

Mo 的第一用户不应理解 Rime、YAML、部署或词库目录。Rime 兼容能力不能决定产品的默认操作模型。

## Decision

- 用户只安装一个签名 `MoSetup.exe`，正常情况下只经历一次 UAC。
- 安装器注册并启用 Mo，但不静默抢占系统默认输入法。
- 默认方案只有“墨·拼音”，随安装包提供预编译词典。
- 用户不手工下载 rime-ice、不复制词库、不执行重新部署。
- 普通设置使用强类型模型；开发者模式才显示 schema、Lua 和部署诊断。
- 更新、修复和回滚由产品管理，永不覆盖用户 profile。

## Consequences

- schema 和上游包成为构建输入，不是普通用户界面。
- 安装成功、首次切换可输入和一键修复成为发布级验收指标。
