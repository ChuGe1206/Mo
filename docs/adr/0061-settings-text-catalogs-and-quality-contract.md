# ADR 0061：设置文案资源与开发质量合同

## 状态

已接受；2026-10-12 在 develop 实施。补充 ADR 0060 的设置呈现层合同。
开发规范的统一入口为 README 的“开发质量规范（项目执行标准）”，AGENTS 引用该入口。

## 决策

设置应用使用独立、不可执行的 UTF-8 文案目录。TextKey 枚举、稳定键名及 ALL 清单
来自同一声明；默认资源为 assets/ui/text/zh-CN.mo、en-US.mo，编译时嵌入。
当前共 97 个键，默认目录必须完整。UI 控件、绘制和辅助功能标题复用同一键。
中文候选预览属于合成输入数据，不随界面语言翻译；未修改词库或输入方案。

格式为固定三行头及 key=value：

```text
mo-ui-text
format=1
locale=zh-CN
comments=候选注释
```

首个等号分隔键和值；头之后允许空行及以 # 开始的整行注释。支持 BOM/CRLF。
格式版本固定为 1；文件最多 32 KiB，单值最多 512 UTF-8 字节，限制不按字符数计算。
拒绝未知/重复键、空值、控制字符、无效 UTF-8 和非法占位符；不解释转义、路径或代码。
模板由键声明命名字段，翻译可调换顺序但不能增减字段集合。替换单次进行，参数不再解析。

用户可在 settings-v1.mo 同目录放置 ui-text-zh-CN.mo 或 ui-text-en-US.mo。
覆盖文件可只含部分键；整份验证完成才覆盖，不完整默认目录不能构造。
可选文件错误保持整份默认资源并显示覆盖拒绝状态，不输出覆盖内容。
读取有界且拒绝已观察到的非普通文件、symlink/reparse；普通文件元数据检查与打开之间
仍有竞争窗口。文案只作为显示数据，不授予外部文件执行或高权限写入能力。

语言选择优先级为 --language > ui-language-v1.mo > zh-CN。启动偏好同样是独立
版本化数据，最多 128 字节，缺失或错误默认中文，启动不写入偏好或引擎设置：

```text
mo-ui-language
format=1
locale=en-US
```

侧栏语言按钮即时切换当前窗口，刷新窗口标题、原生控件标题及下拉选项，保持未保存
设置草稿。它不自动持久化；下次启动通过偏好文件或命令行选择。添加其他语言须新增
资源、UiLocale 分支及完整键测试，目前不接受任意语言名或任意资源路径。

## 常量与边界

持久化外观范围归 mo-settings；设置应用引用该所属定义。mo-ipc 保持独立线协议
边界，Broker 跨组件测试遍历接受范围，防止两端逐渐偏离。协议固定字段使用命名范围，
编码标识在 repr 枚举中显式声明并由 TryFrom 检查；独立 literal golden/CRC 数据验证兼容。
Actor watchdog、连接轮询和 UI 尺寸使用用途/单位明确的常量；50/400 ms 不变。
颜色使用具名调色板记录；整数亮度近似不声明为 WCAG 对比度计算。

所有 crate 继承工作区 lint，安全入口保持 forbid(unsafe_code)。设置启动失败返回
失败退出码。新增模板 expect 仅用于经过构造和字段检查的内部不变量，附说明和测试。

## 安装与验证边界

两份资源加入 stage 的固定 UI 源码清单，以支持封存源码离线重建；无需新增依赖。
本轮不改变设置文件或 IPC 字节格式，不增加逐键 I/O。VM 已安装的 0.0.14.0
不包含这些后续源码变更；语言版本的配套打包及安装态验证尚未完成。
C++ 候选窗口自己的文案尚未接入本目录，不能宣称全产品已经多语言化。
多实际 DPI、OS 高对比度、辅助工具及真实宿主仍需验收；当前只有受控原生预览和回归。

实施和证据见 [质量审查记录](../phase-0/CODE-QUALITY-20261012.md)。
