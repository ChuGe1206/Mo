## 根因与修复

用户确认问题来自主键盘 /? 键。真实 Rime 的合成快慢斜杠均产生提交；
真实 TSF ACP 夹具复现空闲标点的 InsertTextAtSelection(NOQUERY/null-range) 返回 E_INVALIDARG。
原测试只覆盖已存在预编辑时的标点完成，遗漏空闲直接提交。
现用返回插入范围的方式，显式 Collapse/SetSelection 到末尾；插入成功后光标操作失败仍消费键，
避免宿主重复输入。维持原 wire、设置及 50/400 ms，不重放引擎请求。

Windows VK 转换集中在 windows_keys，补齐小键盘/OEM_102 和部分系统键。
Ctrl/Alt/Super、抬键不推断文本；未知/国际/dead/媒体键保持 NoSymbol，交由宿主。
具体范围和 API 来源见 ADR；转译检查不等于所有硬件/布局实际路由通过。
